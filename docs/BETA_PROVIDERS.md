# M15 provider register

Reviewed September 19, 2026. These are engineering release dispositions, **not legal opinions**. Public accessibility is not a license. No provider was contacted or permission obtained during M15. Default flags are conservative; changing one requires a restart and a fresh audit.

| Dependency | Purpose / access / authentication | Frequency, cache, stored data | Attribution / terms evidence | Beta disposition and failure |
|---|---|---|---|---|
| Sleeper | Read-only REST: user, leagues, rosters, NFL state, player metadata; no token | Connection 15m; rosters/state 5m; players 24h (normal refresh does not bypass this). Bounded process caches; process restart/cache clear can refetch. Normalized league identifiers, decisions/evidence/history in SQLite; no passwords | [Official docs](https://docs.sleeper.com/) permit non-commercial use, require discussion for commercial licensing, recommend staying below 1,000 calls/min and fetching the large player map at most daily | **REQUIRES REVIEW** of intended beta/business use. Essential, enabled for local validation; not permission to distribute. Failure: connect error or stale snapshot/unknown evidence |
| nflverse via GitHub releases | CSV/gzip schedules, current/prior weekly stats, snaps, injuries, player identity; no token. Depth-chart method exists but product currently supplies no depth feed | Schedule/current stats/snaps 6h; prior stats/snaps and identity rows 24h; injuries 1h; derived indexes 5m/identity map 1h. RAM data caches; only derived recommendation evidence persisted | [Data repo](https://github.com/nflverse/nflverse-data) publishes [CC BY 4.0](https://github.com/nflverse/nflverse-data/blob/main/LICENSE.md). FanEdge transforms/joins these data. [Snaps originate from PFR](https://nflreadr.nflverse.com/reference/load_snap_counts.html); third-party source rights and dataset exceptions require confirmation. Package MIT licensing is not proof of data rights | **APPROVED WITH LIMITATIONS** for local validation under attribution; **REQUIRES REVIEW** of upstream/source scope before distribution. Missing rows never imply bye/zero; unavailable data reduces confidence |
| ESPN NFL RSS | Optional XML endpoint; no scraping/article-body fetch, no auth | 15m RAM facts; normalized attributed reports/excerpts retained in SQLite news cache/history when enabled | [Feed](https://www.espn.com/espn/rss/nfl/news). A reachable feed does not establish redistribution permission; no suitable product license verified | **DISABLE FOR BETA**, `FANEDGE_NEWS_ENABLED=0`. Disabled capability is visible; no request made. Existing historical journal evidence is not automatically erased |
| ESPN player headshots | Browser CDN GET derived from ESPN player ID; no auth | Browser-managed cache; no Python image download or bundled image library; only URL if enabled | `a.espncdn.com/i/headshots/nfl/players/full/{id}.png`. No product reuse permission established | **DISABLE FOR BETA**, `FANEDGE_PLAYER_IMAGES_ENABLED=0`. Initials/position fallback; no remote image URL in product API |
| ESPN team logos | Browser CDN GET by canonical abbreviation; no auth | Browser cache, no bundled images | `a.espncdn.com/i/teamlogos/nfl/500/{team}.png`. CDN accessibility does not grant trademark/image rights | **DISABLE FOR BETA**, `FANEDGE_TEAM_LOGOS_ENABLED=0`. Text abbreviation/color fallback |
| OpenAI | Optional Responses API phrasing only, server project API key; no browser key | Explicit Ask submission only. gpt-4o-mini; at most 24,000 input characters (roughly 6k tokens for ordinary English, not a tokenizer guarantee), 320 output tokens, 8s SDK timeout, zero retries, `store=False`. 30 calls/hour and 100/day/process. Scoped identical Ask requests reuse work for 30s; bounded RAM conversations last 1h | [Data controls](https://developers.openai.com/api/docs/guides/your-data): API data not used for training by default; abuse-monitoring retention can still apply despite `store=False`. Operator must review account terms and disclose question/context transmission before enabling | **APPROVED WITH LIMITATIONS**, but **off by default**, `FANEDGE_AI_ENABLED=0`. Deterministic answers survive disabled, timeout, rate limit, invalid output and provider failure. No live model calls/spend needed for M15 tests |
| Fantasy Football Calculator | Optional documented ADP JSON adapter; no auth | Daily cache; 5s timeout. No market DB bundled. Exact identity + date/sample/format gates. No in-season value claims | [Official usage](https://help.fantasyfootballcalculator.com/article/42-adp-rest-api) explicitly permits personal/commercial use and requests attribution; data updates daily | **APPROVED WITH LIMITATIONS**, opt-in `FANEDGE_MARKET_ADP_ENABLED=0` default. Failures/low samples mean uncalibrated deterministic trades |
| Local fonts, icons, framework assets | Lucide SVGs and local/system fonts; Next/React/React Query/FastAPI/requests/OpenAI SDK/SQLite, legacy Streamlit | Installed dependency distributions, lockfile; no runtime font/CDN analytics service | Preserve dependency licenses. No Google Fonts, third-party analytics SDK, payment or tracking service added | **APPROVED WITH LIMITATIONS** subject to dependency/security review. The runtime source search found no other remote data/asset provider |

FantasyPros, FantasyCalc, KeepTradeCut and SportsDataIO are not integrated runtime dependencies. Prior research is not authorization to enable them. The legacy Streamlit reference is not the beta deployment; its three optional strategy generation functions now have input/output/timeout/storage controls as well, but are not routed by FastAPI.

## Required before inviting testers

Resolve Sleeper intended-use classification/licensing with the owner, and record upstream nflverse dataset disposition. Keep ESPN off unless rights are documented. Deploy a single backend worker behind invite-only access; set OpenAI project-side spending controls before enabling optional prose (process-local limits reset on restart and are not a billing cap). Review accessibility/privacy for any external images. Attribution is provided in-product; FanEdge is not endorsed by providers or the NFL.
